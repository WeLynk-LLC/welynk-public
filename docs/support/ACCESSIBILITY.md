# Accessibility

**Last Updated:** January 2026

---

WeLynk is committed to creating an inclusive experience for all users.

## Our Approach

We design and build with accessibility in mind:

- Keyboard navigation support
- Screen reader compatibility
- Sufficient color contrast
- Clear visual feedback
- Accessible web and mobile apps

We continuously work to identify and remove barriers that may prevent anyone from fully using our platform.
